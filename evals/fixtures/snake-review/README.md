# Pocket Arcade — Snake

A responsive, dependency-free browser game.

Run `npm start` and visit http://localhost:5173. Run `npm test` for game-engine checks.

Use arrow keys or WASD to turn, Space to start/pause/resume, and R to restart. On mobile, use the direction buttons or swipe on the board. Eat fruit for 10 points; hitting a wall or yourself ends the round. Choose Chill, Classic, or Fast at any time. Your best score is saved locally when browser storage is available.
